ToneOp
Fitness App Redesign
01
UX Case Study · Fitness App
ToneOp — Stats & Burn Screen Redesign
Redesigned the core Stats/Burn tracking screen of ToneOp fitness app to improve data clarity, reduce cognitive load, and boost user engagement through better visual hierarchy.
RoleUX Designer (Contract)
Duration2023
ToolsFigma, HTML/CSS
UX ResearchRedesignFitnessPrototypingUX Writing
View Full Case Study ↗
🔍 The Problem

ToneOp's Stats/Burn screen presented complex fitness data in a cluttered layout that made it difficult for users to quickly understand their daily progress. Key metrics were buried, calorie visualization was confusing, and the screen lacked a clear hierarchy — leading to user drop-off from a critical engagement touchpoint.

⚙️ Design Process
01
Heuristic Audit
Analyzed existing screen against Nielsen's 10 heuristics, documented 15+ usability issues
02
User Research
Identified key pain points around data overload and unclear progress indicators
03
Wireframing
Sketched 3 layout alternatives, explored card-based vs list-based data presentation
04
Hi-Fi Design
Delivered pixel-perfect Figma screens with interactive calendar prototype
05
Documentation
20-point solutions summary, design rationale document, case study PDF
💡 Key Design Decisions
📊
Data Hierarchy
Prioritized primary metric (calories burned) with large display, secondary stats in supporting cards
📅
Interactive Calendar
Replaced static date view with swipeable weekly calendar for quick period navigation
🎨
Visual Encoding
Used color-coded progress rings and micro-charts to make data scannable at a glance
✍️
UX Copy
Rewrote all microcopy to be motivating, clear, and action-oriented

🔍 The Problem

Passport Seva
Government App Redesign
03
UX Case Study · Government App
Passport Seva App — UX Redesign
Redesigning India's Passport Seva portal to reduce form abandonment, simplify the appointment booking flow, and make government services accessible to all literacy levels.
TypeUX Case Study
FocusGov. Service UX
ToolsFigma, Research
UX ResearchGovernment UXAccessibilityUser Testing
View Full Case Study ↗
🔍 The Problem

India's Passport Seva app suffered from complex navigation, jargon-heavy forms, and poor error handling — causing high abandonment rates, especially among first-time applicants. The challenge was to redesign for clarity, trust, and accessibility across diverse user demographics.

⚙️ Design Process
01
User Research
Surveyed users, identified top pain points: confusing forms, unclear status tracking
02
Personas
Created 3 personas: first-time applicant, renewal user, low-literacy rural user
03
Journey Mapping
Mapped full application journey, identified 8 critical drop-off points
04
Redesign
Simplified forms into progressive steps, added clear status tracker and help tooltips
💡 Key Outcomes
📝
Simplified Forms
Broke multi-page form into 5 guided steps with contextual help
🔔
Status Tracking
Clear visual status tracker replacing opaque text-based updates
♿
Accessibility
WCAG 2.1 compliant design with large touch targets and plain language
